# Game Boy stage model

“GameBoy DMG-01” by
[Let's Do 3D](https://sketchfab.com/LetsDo3D) is licensed under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The original model
page is available on
[Sketchfab](https://sketchfab.com/3d-models/gameboy-dmg-01-29849a15fe0a40a6a18e01c9d544a0ed).

Pocket Voxel removes the sample scene, all image textures, branded product
decals, and the glass overlay; rebuilds the retained materials from unbranded
colors; and adds a UV-mapped dynamic screen surface for the live game. The
redistributable, de-branded source is stored at
`source/lets-do-3d-gameboy-dmg-01.glb`. The authenticated upstream Blender
download used to produce it has SHA-256
`9658ca66dc7f87d893b7acad9b5d2a4070a14edf9ba7ff24969cda2ba75bcfef`.
