# Game Boy stage model

“Gameboy” by [Jason Toff](https://poly.pizza/m/dczUnD4aslM) is licensed under
[CC BY 3.0](https://creativecommons.org/licenses/by/3.0/).

Pocket Voxel modifies the source model by removing the sample scene, replacing
its palette, and adding a UV-mapped dynamic screen surface for the live game.
The original model is stored in the source repository at
`source/jason-toff-gameboy.glb`; its SHA-256 is
`5c5eced2ffa9b19c6372d4e160921f3e94bfd3b5b9f8c80fe6c0e313cdd6a943`.
